World server console

Send world commands with or without the leading dot. Shutdown and restart use the normal player-save sequence.

Countdown: server shutdown 300 or server restart 300 (seconds). At a clock time: server shutdown time 23:00 or server restart time 23:00 (server local time; next occurrence). Cancel: server shutdown cancel or server restart cancel.

Add or edit a world node

Each world needs its own configuration, realm ID and listening port. Nodes share the hub's auth database. Save a name at any time; stop the node before changing launch paths. Saving does not start the server.
